# Changelog

All notable changes to the SpaceLoop platform will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-07

### Added
- **Full Living Hero Environment**: Cinematic entrance timeline with sky gradient, rising architecture, descending brand typography, and smooth page-lift scroll effect.
- **Enterprise Navigation**: Full-width header spanning edge-to-edge with Infinity brand logo and left-side hamburger menu housing "How It Works", "List a Space", and "Bookings".
- **Theme Engine**: Complete dual-mode light/dark architecture with real-time reactive theme toggling.
- **Smart Access & Escrow Backend**: Multi-layered reservation system with PIN generation, QR credentials, and milestone escrow release.
- **AI Concierge (LoopBot)**: Contextual assistant powered by LLM search pipelines and natural-language constraint matching.
- **Trust & Safety Fraud Engine**: Real-time graph analysis, KYC verification adapters (Aadhaar, UPI, Electricity Discom, Student ID), and risk scoring.
- **Admin Governance Portal**: Multi-role platform dashboard for dispute management, space review, user audits, and security telemetry.
